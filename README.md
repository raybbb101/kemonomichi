# けものみち — KEMONO MICHI

動物や昆虫になって、仲間と一緒に敵に立ち向かう **HD-2D 協力型ローグライク** です。
ブラウザだけで動き、**ルームコードを友だちに送るだけ**で一緒に遊べます（サーバー不要）。

- 3D の地形・光・影の中にドット絵のキャラクターが立つ HD-2D 表現（ブルーム・ティルトシフト・ビネット）
- 8種類の動物から1体を選んで冒険（イヌ・ネコ・ウサギ・ヘビ・カニ・サル・チョウ・カブトムシ）
- 各動物に **通常攻撃 / スキル / 特殊スキル / パッシブ / 必殺技** と「得意技」
- ステージ型ローグライク：戦闘・仕掛け・なぞなぞ・レベルアップで成長
- **5ステージごとに商人**、**10ステージごとにボス**
- **ステージ50で融合**：もう1体の動物と合体し、この世界に存在しない新種族（全28種）に

## 遊び方

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 移動 | WASD / 矢印 | 左スティック |
| 通常攻撃（押しっぱなしで連続） | J / Z | A |
| スキル | K / X | X |
| 特殊スキル | L / C | Y |
| 必殺技（ゲージ100%） | I / V | RB / RT |
| 回避 | Space / Shift | B |
| 調べる・話す | E / Enter | LB |
| レベルアップの成長を選ぶ | 1 / 2 / 3 | — |
| 音のオン・オフ | M | — |

攻撃は近くの敵へ自動で向きます。仲間が倒れたら、そばに立ち続けると復活させられます。全員が倒れるとゲームオーバー。

### マルチプレイ
1. 1人が「ルームを作る」→ 5文字のルームコードが表示される
2. 他の人はコードを入れて「参加」
3. 全員が動物を選んで「準備OK」→ ホストが「冒険に出発」

途中参加もできます（ロビーで動物を選ぶと、進行中のステージに合流）。

### 得意技とステージの仕掛け
ステージには、特定の動物が得意な「おまけ」が置かれます。いろんな動物でパーティを組むほどお宝が増えます。

- 水に沈んだ宝箱 → 泳げる・飛べる動物
- 谷の向こうの小島の宝箱 → 大跳躍・飛行
- キラキラした地面 → 穴掘りが得意なら一瞬（他の動物は長押しで頑張って掘る）
- 崖の小さなすき間 → 細い体の動物
- 木の実がなる木 → 木登りが得意な動物（全員回復）
- 重い岩 → 怪力の動物は楽に押せる

ポータルを開けるための仕掛けは、どの動物でも解けます：
**床スイッチ**（2つ同時に押す・岩も使える）／**なぞなぞの石碑**（正しい祭壇で答える）／**光の柱**（石碑の示す順番に叩く）

### 商人と覚醒アイテム
5ステージごとの休憩所にタヌキの行商がいます。
「○○専用」のアイテムは、その動物が持つと **スキルが覚醒** したり特別な強化がつきます。
仲間の動物の専用品を買うと、**その仲間に贈る**ことができます。

### 融合（ステージ50）
50ステージ目のボスを越えた先の休憩所に「融合の祭壇」が現れます。
もう1体の動物を選んで融合すると、新しい種族が生まれます。

- ベースの動物から：**通常攻撃・スキル**・見た目の体
- 相方の動物から：**特殊スキル**・パッシブ・得意技・特徴パーツ（耳・羽・角・鋏…）
- 融合種だけの **融合特性** と **必殺技**

組み合わせは全28種（タイトル画面の「融合種 図鑑」で全部見られます）。
例：イヌ×チョウ＝パピヨンロウ（蝶翼の聖犬）、ヘビ×チョウ＝ククルカン（羽ある蛇神）、カニ×カブトムシ＝ギガントシェル（不動の要塞）

## ローカルで動かす

ビルド不要です。静的ファイルを配信するだけで動きます。

```bash
python3 serve.py
```

ブラウザで http://localhost:8765 を開きます。

開発用の URL パラメータ（ソロ・ホストのみ）:
- `?stage=10` … ステージ10（ボス）から開始
- `?stage=50&rest=1` … 融合の祭壇がある休憩所から開始

## GitHub Pages で公開する

1. このフォルダを GitHub の新しいリポジトリに push
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

マルチプレイの接続には PeerJS の無料シグナリングサーバー（0.peerjs.com）を使っています。ゲームのデータはプレイヤー同士が直接（WebRTC）やり取りします。

## ファイル構成

```
index.html        画面の骨組み
style.css         UI のデザイン
serve.py          開発用ローカルサーバー
src/main.js       画面遷移・入力・通信の受け渡し・HUD・お店・融合
src/data.js       動物・スキル・融合種28種・アイテム・敵・地域・なぞなぞ
src/sprites.js    ドット絵の自動生成（図形→陰影→縁取り、融合種のパーツ合成）
src/world.js      HD-2D レンダラー（Three.js・影・光・ポストエフェクト・エフェクト）
src/stage.js      シードからのステージ生成（全員が同じ地形を作る）
src/sim.js        ホスト側のシミュレーション（敵AI・ボス・弾・仕掛け・進行）
src/player.js     操作キャラクター（移動・スキル実行・成長）
src/net.js        ルームコード式 P2P 通信（PeerJS）
src/audio.js      効果音と BGM の合成（音声ファイル不要）
```

画像・音声ファイルは一切使っていません。キャラクター・地形・音はすべてコードで生成しています。
